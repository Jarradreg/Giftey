# Giftey
Giftey is a fun open-source giveaway bot that makes it easy to run exciting giveaways in your community. What’s great is that you can customise it to fit your style and needs since it’s open-source. 

Just keep in mind that we don’t host Giftey; you'll need to set it up on your own server. This gives you full control to adapt and modify it as your community grows. 

Get ready to engage your followers and create memorable experiences with Giftey!

# How to host
For hosting, we recommend using Railway. It offers a free trial, but could require payment based on usage. You can always get help in the developer Discord server.
